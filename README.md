# RAGBench Documentation

This repository contains the official documentation for **[RAGBench](https://github.com/Omkar-S-Kulkarni/ragbench)** - a layered, independent, auto-chainable RAG framework.

## 📚 View Documentation

**Live Documentation**: https://omkar-s-kulkarni.github.io/docsforragbench/

## 📖 What's Inside

- **Getting Started**: Quick start guides, installation instructions, architecture overview
- **Comprehensive Guides**: Complete guides covering all RAGBench features (Part 1 & 2)
- **Layer Documentation**: Deep dives into each of the 7 RAG layers
- **API Reference**: Complete API documentation
- **Configuration**: Setup and configuration guides
- **Use Cases**: Task-specific implementation guides
- **Troubleshooting**: Common issues and solutions
- **Contributing**: Developer guides for contributors

## 🔧 Building Locally

This documentation is built using [MkDocs](https://www.mkdocs.org/) with the [Material theme](https://squidfunk.github.io/mkdocs-material/).

### Prerequisites

```bash
pip install mkdocs mkdocs-material mkdocstrings[python]
```

### Build & Serve

```bash
# Serve locally at http://127.0.0.1:8000
mkdocs serve

# Build static site
mkdocs build

# Deploy to GitHub Pages
mkdocs gh-deploy
```
